# Fonts

`Minecraft-*.woff2`: "Minecraft" (Regular, Bold, Italic, Bold Italic), version 1.000,
© 2017 Jacob Debono (JDGraphics Fonts). A fan-made typeface in the style of the game's
text, not Mojang's own font file. Its licence record reads "Free for Commercial Use".
Converted from the OTF files to WOFF2 (ttf2woff2), otherwise unchanged.

Used only by the wiki's minecraft components (apps/web/src/styles/wiki-minecraft.css).
